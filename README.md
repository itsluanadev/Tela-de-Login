# Tela de Login

Tela de login criada com HTML e CSS, com campos de usuário e senha e layout simples e limpo. 

## Tecnologias

- HTML
- CSS 

## Como visualizar

Baixe o repositório e abra o arquivo `index.html` no navegador.


## O que aprendi

- Criação de formulários em HTML
- Estilização de campos e botões com CSS
